# Interfaces

You can work with Ersilia in three ways, all built on the same cycle: fetch a model, serve it, run it on your inputs, and close it.

* **Command line interface**: every `ersilia` command and option.
* **Python API**: the same cycle from Python, returning results as pandas DataFrames, for scripts and notebooks.
* **The** [**Ersilia MCP server**](https://github.com/ersilia-os/ersilia-mcp): lets an AI agent, such as Claude, search the catalog and run models for you. It uses the same Ersilia installation, so everything on these pages applies to it too.

These pages are full references. If you're new to Ersilia, start with [Local inference](../../local-inference.md), which walks you through installation and your first run.
